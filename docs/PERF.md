## なぜ v1 キーが残っているか

`stations` / `cards` / `alerts` / `activity` / `vitals` は v1 画面と `tools/shots.mjs` のため。
v2 画面は `sessions[]` / `log[]` / `history[]` / `counts` / `overall` しか読まない。
**ペイロードの66%が誰も読まないデータ**なので、既定で落とす（互換は明示フラグ）。

## 消してはいけないもの

- `sessions[].lastOutputAt` / `lastOutput` / `runningSince` の **null**（推測で埋めない）
- `log` は新しい順・最大40行の契約（軽量化で**古い行を捨てるのは可**、新しい行を捨てるのは不可）
- WS は毎回**全体**スナップショット（差分にしない。ズレの温床になる）
- 状態の判定はサーバ1箇所（クライアントで再実装しない）

## 測定の作法

- 比較するときは**同じ条件**で: 同じシナリオ（`?scenario=`）・同じセッション数・同じログ行数
- モックで測る `snapshot()` と、実機で測る payload は別物。混ぜて議論しない
- 画面側の軽量化は「描画回数」で測る（体感ではなく回数）
